## About the Game

**Lift the Balls** is a lightweight experimental puzzle game. 
The goal is simple: lift all the balls up to complete each challenge.

This project was created primarily as an **experiment to evaluate the capabilities of AI in the game development workflow**.  
AI Agent was used for programming gameplay mechanics and development tools.



The goal of this project was to explore how AI can help accelerate **rapid prototyping, tool creation, and gameplay iteration**.
